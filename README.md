# 🪕 工工四エディタ (Kunkunshi Editor)

沖縄三線の楽譜 **工工四（くんくんしー）** を、ブラウザで「作る・聴く・編集する・印刷する・音声/MIDI/Excel書き出し」ができるWebエディタです。
箏の文化譜エディタ（koto-note）をもとに、三線用に作り替えました。

---

## 🌟 主な特徴

- **2つの楽譜の形をボタンひとつで切り替え**（入力した内容は共通）
  - **縦書き工工四**：作文用紙のようなマス目に、上から下・右の列から左の列へ。1マス＝1拍。マスの右の細い列に歌詞。
  - **タブ譜**：3本の線（上から 女弦・中弦・男弦）の上に勘所の字を書く横書きの譜面。線の上の字を「ドレミ」にも切り替えられます。
- **勘所キー**：男弦（合・乙・老・下老）・中弦（四・上・中・尺）・女弦（工・五・六・七・八・九）を弦ごとに並べたボタン。
- **合わせ（2本同時）**：「合わせ」ON か Shift を押しながらで、同じマスに別の弦の音を重ねる（同じ弦の音は入れ替わる）。
- **奏法記号**：♯・♭（勘所を半音ずらす）、打（ウチ）、掛（カキ）、押し上げ、スリ、揺り、スクイ、トレモロ、消音、押さえる指（人・中・小）。
- **ちんだみ（調弦）**：本調子・二揚げ・三下げ・一揚げ・カスタム。高さは 1本〜12本（4本＝C）。
- **三線の音で再生**：弦ごとに音が切れる（同じ弦で次の音を弾くと前の音が止まる）、打・掛は柔らかい音、押し上げ・スリ・揺りは音程が動きます。
- **仮想三線**：棹（さお）の図の勘所を押して入力・試聴。再生中は鳴っている弦が光ります。
- **書き出し**：WAV・MIDI（音色は Shamisen）・Excel（縦書き譜面／一覧／調弦）・JSON・印刷（A4 縦/横・PDF）。
- **3Dの手（仮想三線）**：棹を押さえる左手を3Dで表示。いまのマス（演奏中は鳴っている音）の勘所を、どの指で押さえるかを形で見せます。ななめ・自分目線・正面・横から、ドラッグで回転、半透明にもできます。手の形の計算は、ウクレレ・ハンドガイド／ギター・ハンドガイドと同じしくみ（骨の入った手のモデルを、関節の角度を計算して動かす）を三線用にしたものです（`src/hand3d/`）。
  - 三線の形は実寸の目安（全長約80cm・棹の長さ一尺五寸八分＝約47.9cm・胴約18×19cm）で、天の反り・カラクイ・野坂と鳩胸・ティーガー・ウマ・棹の先まで作っています。棹の表の色の線は勘所シール（本手で押さえる指の色）です。
  - 左手は「本手」（人差指＝乙・上・五、中指＝老・中・六、小指＝下老・尺・七）と「尺位」（人差指＝下老・尺・七、中指＝八、小指＝九）を、前後に 八・九 があるかで切り替えます。マスに指番号を書くと、その指で押さえます。
- **見本の曲**：きらきら星、さくらさくら、琉球音階の練習（オリジナル）。

### 勘所と音の高さ（4本 本調子 C・F・C のとき）

| 弦 | 勘所 |
|---|---|
| 女弦 | 工(ド) 五(レ) 六(ミ) 七(ファ) 八(ソ) 九(ラ) |
| 中弦 | 四(ファ) 上(ソ) 中(ラ) 尺(シ♭) ※シは「尺♯」 |
| 男弦 | 合(ド) 乙(レ) 老(ミ) 下老(ファ) |

勘所は曲や流派で少し動くことがあるので、♯・♭ で半音ずつ調整できます。

## 🎹 キーボード操作（PC向け）

物理キーの位置で判定するので、日本語入力がONでも、JIS・US どちらの配列でも同じように動きます。

| 操作 | キー |
|---|---|
| **男弦 合・乙・老・下老** | `1` `2` `3` `4` |
| **中弦 四・上・中・尺** | `5` `6` `7` `8` |
| **女弦 工・五・六・七・八・九** | `9` `0` `-` `^` `¥` `@` |
| **合わせ（2本同時）** | `Shift` を押しながら勘所キー |
| **音の長さ** | `Q` 4分（1マス1音）　`W` 8分　`E` 3連　`R` 16分 |
| **休符 ／ 延ばし** | `P` または `.` ／ `T` または `,` |
| **♯ ／ ♭** | `Z` ／ `X` |
| **打・掛・押し上げ・スリ・揺り** | `U` `K` `Y` `I` `M` |
| **スクイ・トレモロ・消音** | `C` `N` `V` |
| **移動** | 矢印キー、`Enter` 次の小節へ、`Home` `End` 先頭・末尾 |
| **消す** | `Delete`、`Backspace` |
| **再生** | `Space` 再生／一時停止、`Shift`+`Space` カーソルから、`Esc` 停止 |
| **元に戻す / やり直し** | `Ctrl`+`Z` ／ `Ctrl`+`Y` |
| **コピー / 切取 / 貼付** | `Ctrl`+`C` ／ `Ctrl`+`X` ／ `Ctrl`+`V` |
| **新規 / 印刷 / 保存** | `Ctrl`+`N` ／ `Ctrl`+`P` ／ `Ctrl`+`S` |

## 🛠 開発とビルド

```bash
npm install        # 依存関係のインストール
npm run dev        # 開発サーバー起動（Vite）
npm run build      # プロダクションビルド
npm run lint       # 型チェック
npm test           # 自動テスト（勘所の音・再生の時間表・奏法・MIDI・Excel）
```

### 内部の構成

- `src/types/kunkunshi.ts` … 勘所・調子・奏法などのデータ定義
- `src/components/ScoreSheetVertical.tsx` … 縦書き工工四（作文用紙のような形）
- `src/components/ScoreSheetTab.tsx` … タブ譜（3本線）
- `src/audio/timeline.ts` … 譜面を「何拍目に・どの音を・何拍ぶん」の時間表にする
- `src/audio/voicing.ts` … 奏法記号を実際の発音に展開する
- `src/audio/sanshinSynth.ts` … 三線の音（Karplus-Strong 方式）
- `src/utils/wavExport.ts` / `midiExport.ts` / `xlsxExport.ts` … 書き出し

`main` に push すると GitHub Pages に公開されます（`.github/workflows/deploy.yml`）。
